# Tableau de bord DEPHY maraîchage

Page de lecture du tableau de bord national DEPHY maraîchage (`Tableau_bord_MARAICHAGE_<date>.xlsx`).

Ouvrir la page, puis choisir le fichier `.xlsx` reçu de la cellule nationale. Le fichier est lu dans le navigateur : il n'est envoyé nulle part, et la page ne contient aucune donnée.

Source de la page : `scripts/dephy/tableau-de-bord-dephy.html` du dossier de travail APABA. Ce dépôt n'en est qu'une copie publiée.
